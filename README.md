## Sobre o Jogo

O projeto consiste na recriação do clássico jogo **Brick Breaker (Breakout)**, onde o jogador controla uma plataforma móvel (*paddle*) para rebater uma bola e destruir paredes de tijolos organizadas em matrizes.
